## Descripción del proyecto
Este repositorio contiene la resolución de la Práctica de la Unidad 2 del módulo Sistemas de Gestión Empresarial (SGE). Consiste en una comparativa técnica y de licencias entre diferentes sistemas ERP y CRM del mercado (libres y propietarios), terminando en una matriz de decisión y una propuesta de implantación justificada para el caso empresarial asignado.

## Estructura del repositorio
- `README.md`: Información general del proyecto y datos 
- `comparativa.md`: Documento principal que contiene el análisis de licencias, las fichas técnicas de los sistemas seleccionados, la fe de erratas del temario y la recomendación final.
- `matriz_decision.csv`: Matriz ponderada de criterios utilizada para evaluar de forma objetiva las soluciones propuestas para la empresa.
